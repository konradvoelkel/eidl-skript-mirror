% --- Gemeinsamer Block der HHU-Skripte (PLAYBOOK 3.8i) --------------------------------
% Alles hier gilt fuer *jedes* deutschsprachige Skript der Familie und ist zwischen den
% Buechern kopierbar. Was nur diesem Buch gehoert -- Markenfarbe, PDF-Metadaten,
% \setminted -- steht nicht hier, sondern in `options.preamble` in der myst.yml.
%
% Der Block gehoert **direkt hinter \documentclass** und vor `datetime`/`hyperref`: Wird
% babel erst danach geladen, steht auf der Titelseite "Saturday 26. September, 2026"
% statt "27. September 2026". Genau so war es hier bis zum 2026-09-27.
%
% amssymb: MyST importiert von sich aus nur amsmath; das Buch benutzt \mathbb, \square, ...
\usepackage{amssymb}
% caption: MyST erzeugt \caption* fuer Abbildungen ohne Label, das es sonst nicht gibt
\usepackage{caption}
% Deutsche Trennung (texlive-lang-german liegt im CI-Image). `shorthands=off` ist Pflicht:
% babels deutsche Kurzbefehle machen `"` aktiv, und das Buch ist voller Codebloecke.
% microtype kostet nichts und wirkt auf jeder Seite (haengende Satzzeichen, Laufweite).
\usepackage[shorthands=off,ngerman]{babel}
\usepackage{microtype}
% A4 mit massvollen Raendern statt der US-Letter-Vorgabe von `article`
\usepackage[a4paper, margin=2.5cm]{geometry}
% xelatex: Latin Modern fuer den Text, DejaVu Sans Mono fuer Code (fonts-dejavu-core).
%
% `Scale=0.872` ist nicht geraten, sondern gerechnet: Der Zeichenvorschub von lmmono10
% ist 0.5250 em, der von DejaVu Sans Mono 0.60205 em; 0.5250/0.60205 = 0.872. Damit sind
% die Zeichenbreiten identisch zur Schreibmaschinenschrift, die LaTeX sonst genommen
% haette -- ein Schriftwechsel aendert dann keinen einzigen Zeilenumbruch. Wer die
% Schrift wechselt, rechnet den Faktor neu aus (fontTools, `advanceWidth` / `unitsPerEm`).
% `MatchLowercase` stand hier bis zum 2026-09-27; es passt die x-Hoehe an statt der
% Breite und ist damit fuer Code die falsche Groesse.
\usepackage{fontspec}
\setmonofont{DejaVu Sans Mono}[Scale=0.872]
% Schreibmaschinenschrift **im Fliesstext** darf trennen. Ohne das laufen lange
% Bezeichner (`torch.backends.mps.is_available()`, `sklearn.datasets.make_moons`) in
% den Rand, weil LaTeX in \texttt keine Trennstelle sucht: 18 ueberlange Zeilen im Lauf
% vom 2026-09-27, alle dieser Klasse. `hyphenat` gehoert **hinter** fontspec und
% \setmonofont, sonst greift die Umdefinition von \ttfamily an der falschen Schrift an.
% Codebloecke sind nicht betroffen -- in Verbatim-Umgebungen wird ohnehin nicht getrennt.
\usepackage[htt]{hyphenat}
% Was danach noch ueberhaengt, sind URLs im Linktext (MyST setzt sie als gewoehnlichen
% Text in \href, nicht als \url, also greift keine URL-Trennung). `emergencystretch`
% gibt LaTeX in einem letzten Durchgang zusaetzlichen Dehnraum, statt die Zeile in den
% Rand laufen zu lassen -- der klassische Ausweg, wenn eine Zeile keine Trennstelle hat.
\setlength{\emergencystretch}{3em}
% jedes Kapitel (= \section, eines je .md-Datei) beginnt auf einer neuen Seite
\usepackage{etoolbox}
\pretocmd{\section}{\clearpage}{}{}
% `##` im Markdown wird in diesem Buch zu \paragraph -- und \paragraph ist in `article`
% ein **run-in**-Titel (negativer Abstand danach): Er erscheint erst dort, wo der naechste
% gewoehnliche Absatz beginnt. Folgt auf die Ueberschrift sofort eine Umgebung (eine
% Merkbox, ein Codeblock, eine Liste), wandert der Titel an dieser vorbei -- im Lauf vom
% 2026-09-27 bei **76 von 979** Ueberschriften, die dadurch *hinter* ihrem eigenen
% Abschnitt standen (am deutlichsten in Blatt 0: "Lineare Algebra: Laenge" stand unter
% dem Laenge-Abschnitt). Positiver Abstand danach macht daraus eine eigene Zeile.
% Rueckgaengig: diesen \makeatletter-Block loeschen.
\makeatletter
\renewcommand\paragraph{\@startsection{paragraph}{4}{\z@}%
  {2.5ex \@plus 1ex \@minus .2ex}{0.6ex \@plus .2ex}{\normalfont\normalsize\bfseries}}
\renewcommand\subparagraph{\@startsection{subparagraph}{5}{\z@}%
  {2ex \@plus 1ex \@minus .2ex}{0.5ex \@plus .2ex}{\normalfont\normalsize\bfseries\itshape}}
\makeatother
